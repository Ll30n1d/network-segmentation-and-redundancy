## Цель проекта

Настроить сетевую инфраструктуру с использованием технологий сегментации, агрегации каналов, динамической маршрутизации и резервирования шлюза.

В рамках проекта реализованы VLAN, EtherChannel, OSPF и HSRP. Проверена работоспособность настроенных механизмов, исследованы таблицы маршрутизации, состояния сетевых соединений и переключение резервного маршрутизатора.

## Контекст

Работа выполнялась в изолированной виртуальной лаборатории с использованием GNS3 и сетевых устройств Cisco 3745.

## Ход работы

> Подробный отчёт (конфигурации, результаты проверок, скриншоты): [docs/report.md](docs/report.md)

### 1. VLAN Configuration and Security

Созданы две виртуальные локальные сети (VLAN 10 и VLAN 20) с использованием двух коммутаторов и четырёх виртуальных компьютеров.

Настроены access-порты и trunk-соединение между коммутаторами с использованием IEEE 802.1Q. Проверена связность между устройствами, находящимися в одинаковых VLAN.

Дополнительно реализована усиленная конфигурация trunk с изменением native VLAN для снижения риска VLAN Hopping.

Для работы сохранены две версии проекта GNS3: базовая конфигурация `vlan.gns3project` и усиленная конфигурация `vlan-hardened.gns3project`.

### 2. EtherChannel Configuration

Настроена агрегация двух физических интерфейсов между коммутаторами с использованием EtherChannel.

Проверено состояние логического интерфейса Port-channel, участие физических интерфейсов в агрегированном канале и работа trunk-соединения.

Связность между устройствами в одинаковых VLAN проверена с помощью ICMP (ping).

### 3. OSPF Dynamic Routing

Настроена динамическая маршрутизация между тремя последовательно соединёнными маршрутизаторами Cisco с использованием OSPF в Area 0.

Настроена IP-адресация транзитных соединений и Loopback-интерфейсов. Проверены соседские отношения OSPF, таблицы маршрутизации и доступность удалённых подсетей.

Дополнительно настроена MD5-аутентификация OSPF для защиты взаимодействия между маршрутизаторами.

### 4. HSRP Gateway Redundancy

Настроено резервирование шлюза с использованием Hot Standby Router Protocol (HSRP) на двух маршрутизаторах Cisco.

Настроены виртуальный IP-адрес, роли Active и Standby, приоритеты маршрутизаторов и механизм preempt.

Проверена доступность виртуального шлюза. Дополнительно проведена проверка переключения Active/Standby при отключении интерфейса активного маршрутизатора.

## Анализ сетевой инфраструктуры и применение в SOC

Понимание принципов сегментации, маршрутизации и резервирования важно при анализе сетевой инфраструктуры и расследовании сетевых инцидентов.

В проекте изучены следующие механизмы:

| Технология | Изучаемые особенности |
|---|---|
| VLAN | Сегментация сети и разделение широковещательных доменов |
| IEEE 802.1Q | Передача VLAN-трафика через trunk-соединения |
| EtherChannel | Агрегация физических интерфейсов в логический канал |
| OSPF | Динамический обмен маршрутной информацией и установление соседств |
| OSPF MD5 Authentication | Аутентификация взаимодействия между маршрутизаторами |
| HSRP | Резервирование шлюза и переключение Active/Standby |

Полученные знания применимы при анализе сетевой архитектуры, проверке конфигураций сетевых устройств, исследовании маршрутизации и оценке отказоустойчивости инфраструктуры.

Внедрение SIEM, IDS/IPS и разработка правил обнаружения угроз в рамках данного проекта не выполнялись.

## Результаты

- Настроена сегментация сети с использованием VLAN 10 и VLAN 20.
- Настроены trunk-соединения и дополнительные меры защиты от VLAN Hopping.
- Реализована агрегация физических интерфейсов с использованием EtherChannel.
- Настроена динамическая маршрутизация OSPF между тремя маршрутизаторами.
- Настроена MD5-аутентификация OSPF.
- Настроено резервирование шлюза с использованием HSRP.
- Проверены соседские отношения OSPF, таблицы маршрутизации и сетевая связность.
- Проведена практическая проверка переключения резервного маршрутизатора HSRP.
- Результаты сохранены в виде проектов GNS3 и скриншотов конфигураций и проверок.
